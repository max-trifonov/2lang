# Формат словаря v1

Статус: контракт v1, 2026-10-01 (`LNG-S1-007`). Машинная схема: [`content/schema/dictionary.schema.json`](../content/schema/dictionary.schema.json). Контент: [`content/dictionary/`](../content/dictionary/) — файлы `<язык>.<verbs|nouns|adjectives|adverbs>.json` на частотном каркасе `content/frequency/` (D-24); статьи-черновики ИИ помечены `ext.draft: true` (D-25), выверенная статья пометку теряет. Валидатор — `app/src/features/dictionary`, им же проверяется `content/dictionary/` в `npm run test`.

Словарь — частотные слова изучаемых языков (EN, ES) с переводами, формами, примерами по темам и парой во втором языке. Статьи одного языка могут лежать в нескольких файлах: обычно файл = язык + часть речи (`es.verbs.json`, `en.nouns.json`). Формат пишется руками и генерируется из частотных списков (BL-3) — минимум обязательного, всё остальное по мере наполнения.

## Файл

```json
{
  "format": "2lang/dictionary",
  "version": 1,
  "lang": "es",
  "license": "own",
  "source": "Частотный список …, CC BY-SA 4.0",
  "entries": [ … ]
}
```

| Поле | Обяз. | Смысл |
|---|---|---|
| `format` | да | `"2lang/dictionary"` |
| `version` | да | `1` |
| `lang` | да | язык статей (`en`, `es`) |
| `license` | да | `own` · `public-domain` · `cc0` · `cc-by` · `cc-by-sa` — частотные списки приходят из внешних источников |
| `source` | для `cc-by*` | атрибуция источника |
| `entries` | да | статьи, ≥ 1 |
| `ext` | нет | расширения — единственное место для незнакомых ключей |

## Статья

```json
{
  "id": "tener",
  "lemma": "tener",
  "pos": "verb",
  "rank": 4,
  "irregular": true,
  "ipa": "teˈneɾ",
  "translations": { "ru": "иметь; (tener que) быть должным" },
  "pair": "en:have",
  "forms": {
    "present": ["tengo", "tienes", "tiene", "tenemos", "tenéis", "tienen"],
    "gerund": "teniendo",
    "participle": "tenido"
  },
  "examples": [
    { "es": "Tengo una reserva para dos noches.", "ru": "У меня бронь на две ночи.", "topic": "travel" },
    { "es": "Tenemos que hacer un deploy hoy.", "ru": "Нам нужно сделать деплой сегодня.", "topic": "it" }
  ]
}
```

| Поле | Обяз. | Смысл |
|---|---|---|
| `id` | да | **ключ прогресса слова** (`word:<lang>:<id>`): строчные буквы любого алфавита, цифры, дефис. Обычно = лемма; омонимы — суффиксом (`banco-2`). Лемма в нескольких частях речи языка: простой id — у первой по приоритету глагол → существительное → прилагательное → наречие, у остальных — `<лемма>-<часть речи>` (`solo` — прилагательное, `solo-adv` — наречие). Транслитерировать нельзя: `año` ≠ `ano`. После публикации не меняется |
| `lemma` | да | словарная форма, как её пишут: `tener`, `get up`, `Internet` |
| `pos` | да | `verb` · `noun` · `adj` · `adv` · `pron` · `prep` · `conj` · `det` · `num` · `intj` · `phrase` (устойчивое выражение) |
| `rank` | да | ранг частоты **внутри части речи** языка, 1 — самое частое. По нему «глаголы: 37/500» и порядок изучения |
| `irregular` | нет | неправильный глагол (идут первыми, `D-1` brief) |
| `gender` | у сущ. ES | `m` · `f` · `mf` (*el/la estudiante*) |
| `ipa` | нет | транскрипция без скобок — для подсказок (EN-P2) |
| `rules` | нет | id правил чтения из уроков звучания (BL-18) — подсказка в карточке: «c перед e → [θ]/[s]» |
| `translations` | да | переводы: `{ "<язык>": "строка" }`, ≥ 1 язык, не язык статьи. Несколько значений — через `;` |
| `pair` | нет | статья-пара во втором изучаемом языке: `"en:have"` — мост EN↔ES |
| `forms` | нет | формы, см. ниже. Чего нет в файле, приложение не выдумывает |
| `topics` | нет | темы слова: `travel` · `it` · `daily` |
| `level` | нет | `A1`…`C2` |
| `examples` | желательно | 2–3 бытовых примера по темам |
| `note` | нет | `{ "<язык>": "…" }` — пояснение: управление, ловушка, ложный друг |
| `ext` | нет | расширения |

### Формы (закрытый набор ключей)

| Язык · часть речи | Ключи |
|---|---|
| EN · verb | `s` (3-е лицо), `past`, `participle`, `ing` — у `irregular: true` обязательны `past` и `participle` |
| EN · noun | `plural` |
| EN · adj | `comparative`, `superlative` |
| ES · verb | `present`, `preterite`, `imperfect`, `future`, `conditional`, `subjunctive` — массивы из 6 лиц (yo, tú, él/usted, nosotros, vosotros, ellos/ustedes); `imperative` — 5 (tú, usted, nosotros, vosotros, ustedes); `gerund`, `participle` — строки |
| ES · noun | `plural` |
| ES · adj | `f`, `pl`, `fpl` (женский род, мн. ч., женский мн. ч.) |

Для прочих частей речи `forms` нет. Значение формы — непустая строка; варианты одной формы — через ` / ` (`dreamed / dreamt`).

### Пример

| Поле | Обяз. | Смысл |
|---|---|---|
| `<lang>` | да | предложение на языке статьи |
| `<другой язык>` | да, ≥ 1 | перевод |
| `topic` | да | `travel` · `it` · `daily` |

## Правила проверки

Ошибки блокируют файл, предупреждения нет. Путь — с нуля, как в редакторе: `entries[3].forms.present[2]`.

**Ошибки:**
1. Не JSON — сообщение называет строку и столбец.
2. Структура: нет обязательного поля, незнакомый ключ вне `ext`, неверный тип или значение.
3. `id` не по правилу (строчные буквы любого алфавита, цифры, дефис); повтор `id` в языке (в том числе между файлами).
4. `rank` — не целое ≥ 1; повтор ранга в части речи языка (в том числе между файлами).
5. `gender` у существительного ES отсутствует; `gender` у других слов.
6. Ключ `forms` не из набора для языка × части речи; у времени ES не 6 лиц (`imperative` — не 5); у неправильного глагола EN нет `past` или `participle`.
7. `translations` или пример без перевода; в `translations` ключ языка статьи.
8. `pair` не в виде `<язык>:<id>`, или язык пары — язык статьи.
9. `cc-by*` без `source`.

**Предупреждения:**
1. Пара не найдена в загруженных словарях (второй язык ещё не наполнен).
2. Пример не содержит ни лемму, ни одну из форм (без учёта регистра) — возможно, пример к другому слову.
3. У статьи нет примеров.
4. Нет перевода на русский — язык объяснений (`D-1`).

## Эволюция

Имена полей никогда не бывают двухбуквенными: двухбуквенный ключ — всегда язык (`tr` — турецкий), поэтому переводы — `translations`.

Новые необязательные поля, темы, части речи и ключи форм добавляются без смены `version`. Несовместимое изменение → `version: 2` и конвертер. `id` статьи не меняется никогда: это ключ прогресса.
