# Формат урока v1

Статус: контракт v1, 2026-10-01; отсылки к правилам и разделы справочника — 2026-10-14 (D-38). Виды: `words` — `LNG-S1-008`, `sound` — `LNG-S1-009`, `grammar` — `LNG-S1-010`. Машинная схема: [`content/schema/lesson.schema.json`](../content/schema/lesson.schema.json). Пример: [`content/lessons/`](../content/lessons/). Валидатор — `app/src/features/lessons`, им же проверяется `content/lessons/` вместе со словарём в `npm run test`.

Один урок = один JSON-файл, имя — `<id>.json`. Урок длится 5–7 минут (`D-7`).

## Что в файле, а что генерирует плеер

| Шаг урока (brief) | Откуда |
|---|---|
| 1. Разминка из повторения | плеер: карточки к повторению (FSRS) |
| 2. Новые слова с примерами | файл: `words` — ссылки на словарь; переводы, формы, примеры, озвучка — из словаря |
| 3. Фраза дня | файл: `phrase` |
| 4. Мини-правило на примерах | файл: `rule` |
| 5. Практика: узнать → услышать → вспомнить | плеер: из слов урока и словаря |
| 5. Практика: применить | файл: `exercises` |
| 6. Итог | плеер |

## Заголовок (все виды)

```json
{
  "format": "2lang/lesson",
  "version": 1,
  "id": "es-travel-01",
  "lang": "es",
  "kind": "words",
  "topic": "travel",
  "order": 1,
  "title": { "ru": "В отеле: бронь" },
  "requires": []
}
```

| Поле | Обяз. | Смысл |
|---|---|---|
| `format`, `version` | да | `"2lang/lesson"`, `1` |
| `id` | да | slug `[a-z0-9-]`, **ключ прогресса урока** (`lesson:<id>`), не меняется. Имя файла — `<id>.json` |
| `lang` | да | язык урока: каждый урок — в одном языке |
| `kind` | да | `words` · `sound` · `grammar` |
| `topic` | у `words` | тема пути урока слов: `travel` · `it` · `daily` · `friends`. У звучания и грамматики темы нет |
| `order` | да | место в треке языка: целое ≥ 1, уникально в паре язык × трек. **Трек** = тема для урока слов, вид для звучания и грамматики |
| `code` | нет | тема программы курса (`.flow/curriculum.md`): `ES-P3`, `EN-7` |
| `title` | да | `{ "<язык>": "…" }` — название на языках интерфейса |
| `requires` | нет | id уроков, которые нужно пройти раньше |
| `level` | нет | `A1`…`C2` |
| `see` | нет | **отсылки к правилам** (D-38): id уроков того же языка — обычно тем грамматики, на которые опирается урок. У урока слов — 1–4 темы его мини-правила и фразы дня (генерирует `content/drafts/grammar/link.py`), у темы грамматики — связанные темы. Плеер показывает их ссылками в справочник |
| `ext` | нет | расширения |

## Урок слов (`kind: "words"`)

```json
{
  "words": ["tener", "reserva", "aquí"],
  "phrase": { "es": "Tengo una reserva a nombre de Ana.", "ru": "У меня бронь на имя Анны." },
  "rule": {
    "text": { "ru": "tener = «иметь», а «у меня есть» по-испански — просто tengo: Tengo una reserva." },
    "examples": [{ "es": "Tengo tiempo.", "ru": "У меня есть время." }]
  },
  "exercises": [
    { "type": "fill", "es": "___ una reserva para dos noches.", "answer": "Tengo", "ru": "У меня бронь на две ночи." },
    { "type": "build", "es": "Tengo una reserva aquí.", "ru": "У меня здесь бронь." },
    { "type": "translate", "ru": "У меня нет брони.", "answer": ["No tengo reserva.", "No tengo una reserva."] }
  ]
}
```

| Поле | Обяз. | Смысл |
|---|---|---|
| `words` | да | id статей словаря языка урока — новые слова. Рекомендуется 3–5: глагол + существительное + наречие или прилагательное |
| `phrase` | да | фраза дня: оригинал (`<lang>`) + ≥ 1 перевод, `note` — необязательное пояснение |
| `rule` | нет | мини-правило: `text` — `{ "<язык>": "…" }` (1–3 фразы), `examples` — пары «оригинал + перевод» |
| `exercises` | нет | упражнения «применить», см. ниже |

### Упражнения «применить»

| `type` | Поля | Что делает ученик |
|---|---|---|
| `fill` | `<lang>` — предложение с одним пропуском `___`; `answer` — что вставить (строка или варианты); перевод — желательно | вставляет форму слова |
| `build` | `<lang>` — целевое предложение (≥ 3 слов); перевод; `extra` — лишние блоки-ловушки | собирает фразу из блоков — плеер режет предложение по словам |
| `translate` | перевод-задание (`ru` и др.); `answer` — правильные варианты на языке урока | переводит фразу; сверка без учёта регистра и знаков по краям |

## Урок звучания (`kind: "sound"`)

Алфавит, правила чтения, звуки и ударение (`D-9`, программа — `curriculum.md`, темы ES-P*, EN-P*). Звуки и буквы — **записанное аудио**, слова — голос устройства (`D-13`).

```json
{
  "kind": "sound",
  "code": "ES-P3",
  "order": 3,
  "rules": [
    {
      "id": "es-c-before-e-i",
      "title": { "ru": "c перед e, i" },
      "text": { "ru": "c перед e и i читается как [θ] в Испании и [s] в Латинской Америке; в остальных случаях — [k]." },
      "ipa": "θ / s",
      "audio": "audio/es/sounds/theta.mp3",
      "examples": [{ "es": "cena", "ru": "ужин" }, { "es": "cine", "ru": "кино" }]
    }
  ],
  "exercises": [
    { "type": "pairs", "items": [["casa", "caza"], ["pero", "perro"]] },
    { "type": "read", "items": ["cena", "queso", "gente"] },
    { "type": "dictation", "items": ["ciudad", "guitarra"] },
    { "type": "spell", "items": ["García", "ana.garcia@mail.com"] }
  ]
}
```

| Поле | Обяз. | Смысл |
|---|---|---|
| `letters` | `letters` или `rules` | буквы: `letter` (`ñ`), `name` (`eñe`), `ipa`, `audio` — для алфавита и «продиктуй по буквам»; необязательно (D-48): `sound` — как читается `{ "<язык>": "…" }`, `syllables` — слоги и короткие слова для тренировки, `examples` — слова (оригинал + перевод), `rules` — id правил чтения (должны быть в каком-нибудь уроке звучания) |
| `rules` | `letters` или `rules` | правила чтения: `id` — **глобальный** slug, на него ссылаются статьи словаря (`rules`) и подсказка в карточке слова; `title`, `text` — `{ "<язык>": "…" }`; `ipa`, `audio`; `examples` — ≥ 1 слово (оригинал + перевод по желанию) |
| `exercises` | нет | упражнения звучания, см. ниже |

`audio` — путь от `content/`: `audio/<язык>/….mp3` (`.ogg`, `.m4a`). Файл должен существовать — проверяет тест контента.

### Упражнения звучания

| `type` | `items` | Что делает ученик |
|---|---|---|
| `pairs` | пары разных слов: `[["pero", "perro"], …]` | «услышь и выбери»: слышит одно, выбирает написанное |
| `read` | слова | «прочитай сам»: видит, произносит про себя, слушает, сверяет |
| `dictation` | слова | «диктант»: слышит и печатает |
| `spell` | слова, имена, email, коды | «продиктуй по буквам»: называет буквы, сверяет с названиями из алфавита |

Слова в упражнениях — строки, не ссылки на словарь: минимальные пары берут любые слова.

## Урок грамматики (`kind: "grammar"`)

Программа — `curriculum.md` (темы ES-*, EN-*): паттерн → правило на одном экране → мост → практика → «применить» (`D-8`). Правило попадает в справочник, предложения-трансформации — в повторение.

```json
{
  "kind": "grammar",
  "code": "ES-6",
  "order": 6,
  "words": ["tener", "hacer", "ir"],
  "pattern": [
    { "es": "Tengo que trabajar mañana.", "ru": "Мне нужно работать завтра." },
    { "es": "Tenemos que hacer un deploy hoy.", "ru": "Нам нужно сделать деплой сегодня." }
  ],
  "rule": {
    "formula": "tener que + инфинитив",
    "text": { "ru": "«Нужно, должен сделать» — tener (по лицам) + que + глагол в начальной форме." },
    "table": { "head": ["", "tener que + ir"], "rows": [["yo", "tengo que ir"], ["tú", "tienes que ir"]] },
    "timeline": [{ "from": "now", "until": "future", "label": { "ru": "обязанность сейчас или впереди" } }]
  },
  "bridge": [
    { "lang": "en", "formula": "have to + V", "examples": [{ "en": "I have to work tomorrow.", "ru": "Мне нужно работать завтра." }] }
  ],
  "exercises": [
    { "type": "transform", "es": "Tengo que trabajar hoy.", "into": [
      { "form": "negative", "answer": "No tengo que trabajar hoy." },
      { "form": "question", "answer": "¿Tengo que trabajar hoy?" }
    ] },
    { "type": "choose", "es": "Nosotros ___ que salir a las ocho.", "options": ["tengo", "tenemos", "tienen"], "answer": "tenemos" },
    { "type": "compose", "prompt": { "ru": "Что вам нужно сделать завтра?" }, "sample": "Mañana tengo que ir al aeropuerto." }
  ]
}
```

| Поле | Обяз. | Смысл |
|---|---|---|
| `section` | нет | раздел справочника (D-38): `sentence` (строй, отрицание, вопросы, связки) · `verbs` · `tenses` · `modals` · `nouns` · `adjectives` (и наречия) · `pronouns` · `contrasts` — пары «похоже, но не одно и то же» (make / do, ser / estar; D-46) |
| `words` | нет | id слов словаря, после которых тема открывается (`D-14`); не «новые слова» — состав не проверяется. Каждое слово должно встречаться в каком-нибудь уроке слов (тест контента), иначе тема не откроется |
| `pattern` | да | 3–4 бытовых примера: оригинал + перевод |
| `rule` | да | `text` — 1–2 фразы `{ "<язык>": "…" }`; `formula` — строка; `table` — `head` + `rows` одной ширины; `timeline` — отрезки `from`/`until` из `past` · `now` · `future` с `label` |
| `bridge` | нет | мост: `lang` (не язык урока), `lesson` — id той же темы грамматики в языке моста (ссылка «правило во втором языке»), `formula`, `examples` на языке моста с переводом, `note` |
| `exercises` | нет | см. ниже |

### Упражнения грамматики

| `type` | Поля | Что делает ученик |
|---|---|---|
| `transform` | `<lang>` — утверждение; `into` — `[{ form, answer }]`, `form`: `negative` · `question` · `wh-question` · `imperative` · `polite` · `past` · `future` | «трансформер»: превращает предложение в каждую форму |
| `choose` | `<lang>` с одним `___`; `options` — ≥ 2 разных; `answer` — один из них; перевод — желательно | выбирает форму или время по контексту |
| `fill` | как у урока слов | вставляет форму глагола |
| `build` | как у урока слов | собирает предложение из блоков |
| `compose` | `prompt` — задание `{ "<язык>": "…" }`; `template` — шаблон; `sample` — образец (или варианты) | пишет своё предложение и сверяет с образцом |

Плеер грамматики (LNG-S1-033): паттерн → правило (формула, текст, таблица, линия времени) → мост (только на языки профиля) → практика → итог со ссылкой на карточку справочника и связанными темами. Трансформер — задание на каждую форму, ответ собирается **из блоков первого варианта** (засчитывается любой вариант `answer`); `choose` — выбор из вариантов; `compose` — самоотметка после показа образца. В таблице ячейки без кириллицы набираются как текст изучаемого языка.

## Правила проверки

Ошибки блокируют урок, предупреждения нет. Путь — с нуля: `exercises[1].answer`.

**Ошибки:**
1. Не JSON (строка и столбец); структура: нет обязательного поля, незнакомый ключ вне `ext`, неверный тип или значение; незнакомый `kind`; упражнение не своего вида; `topic` у звучания.
2. Повтор слова в `words`; у фразы, примера правила или `build` нет оригинала или перевода.
3. `fill`: пропусков `___` не ровно один; нет `answer`.
4. `translate`: нет ни задания-перевода, ни `answer`; задание на языке урока.
5. Звучание: нет ни `letters`, ни `rules`; повтор `id` правила в уроке; правило без примеров; в `pairs` не два разных слова; `audio` не по шаблону; пустые `items`.
6. Грамматика: нет `pattern` или `rule`; у примера паттерна или моста нет оригинала или перевода; строка таблицы не той ширины; мост на язык урока; `transform` без `into` или с повтором формы; `choose` — пропусков не ровно один, вариантов меньше двух или повтор, `answer` не из вариантов; `compose` без `prompt` или `sample`.
7. Набор уроков: повтор `id`; повтор `order` в паре язык × трек; повтор `id` правила чтения между уроками; `requires` ссылается на неизвестный урок или на сам урок; имя файла ≠ `<id>.json`; `see` — на неизвестный урок, на урок другого языка, на сам урок или с повтором; `bridge[].lesson` — не на тему грамматики языка моста (`bad_ref`).
8. Набор со словарём: слово из `words` (слов и грамматики) не найдено в словаре языка урока.

**Предупреждения:**
1. Слов меньше 3 или больше 5.
2. Нет глагола, существительного или наречия/прилагательного среди слов (по словарю).
3. Ответ `fill` не похож ни на одно слово урока (ни лемма, ни форма) — упражнение может проверять не то.
4. Нет перевода на русский у фразы дня.
5. Статья словаря ссылается на правило чтения (`rules`), которого нет ни в одном уроке звучания.
6. Примеров в паттерне грамматики меньше 3 или больше 4.

## Эволюция

Имена полей форматов **никогда не бывают двухбуквенными**: двухбуквенный ключ — всегда язык (`to` — тонганский). Поэтому у трансформера `into`, у линии времени `until`, а не `to`.

Новые `kind`, типы упражнений и необязательные поля — без смены `version`. id урока не меняется: это ключ прогресса.
