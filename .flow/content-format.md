# Формат текстов v1 — песни и стихи

Статус: контракт v1 (`D-6`), 2026-10-01. Валидатор — `app/src/features/texts` (`LNG-S1-001`): им же проверяется весь `content/` в `npm run test`. Машинная схема: [`content/schema/text.schema.json`](../content/schema/text.schema.json). Примеры: [`content/texts/`](../content/texts/).

Одна песня или один стих = один JSON-файл в UTF-8. Имя файла рекомендуется писать как `<id>.<lang>.json` (`arroz-con-leche.es.json`). Формат рассчитан на ручное написание: минимум обязательных полей, всё остальное добавляется по мере разбора.

## Главная идея: ключ-язык

В строке, фразе и слове **любой двухбуквенный ключ — это язык** (ISO 639-1: `en`, `es`, `ru`…). Ключ, совпадающий с `lang` текста, содержит оригинал. Остальные ключи — переводы.

```json
{ "es": "Arroz con leche, me quiero casar", "ru": "Рис с молоком, я хочу жениться", "en": "Rice pudding, I want to get married" }
```

Переводов может быть несколько: русский для себя, английский как мост к испанскому (`D-1`).

## Минимальный файл

```json
{
  "format": "2lang/text",
  "version": 1,
  "id": "my-song",
  "kind": "song",
  "lang": "en",
  "license": "personal",
  "title": { "en": "My Song" },
  "stanzas": [
    { "lines": [
      { "en": "First line", "ru": "Первая строка" },
      { "en": "Second line", "ru": "Вторая строка" }
    ] }
  ]
}
```

## Поля

### Текст (корень)

| Поле | Обяз. | Тип | Смысл |
|---|---|---|---|
| `format` | да | `"2lang/text"` | маркер формата |
| `version` | да | `1` | версия формата |
| `id` | да | slug `[a-z0-9-]` | уникальный id текста. Повторная загрузка с тем же `id` **обновляет** текст |
| `kind` | да | `song` \| `poem` | тип |
| `lang` | да | код языка | язык оригинала |
| `license` | да | `public-domain` \| `own` \| `personal` | `personal` — чужой текст для личного пользования: лежит в `content/private/`, входит в поставку (`D-43`) |
| `title` | да | Локализованное | название. Должно содержать ключ `lang`, перевод названия необязателен |
| `author` | нет | строка | автор слов |
| `performer` | нет | строка | исполнитель |
| `year` | нет | число | год |
| `level` | нет | `A1`…`C2` | оценка сложности по CEFR |
| `tags` | нет | строки | темы: `travel`, `it`, `love`, `kids`… |
| `links` | нет | Ссылка[] | `{ "type": "youtube" \| "audio" \| "source", "url": "…" }` |
| `note` | нет | Локализованное | комментарий к тексту целиком |
| `see` | нет | строки | id тем грамматики языка текста (`en-grammar-07`), которые встречаются в тексте: урок по песне показывает их, тема — песни с ней (`D-42`) |
| `stanzas` | да | Строфа[] | содержимое, ≥ 1 строфы |

**Локализованное** = объект `{ "<язык>": "строка" }`, например `{ "ru": "Про идиому…" }`.

### Строфа

Либо свои строки, либо ссылка на другую строфу (повтор припева без копирования).

| Поле | Обяз. | Смысл |
|---|---|---|
| `id` | если на строфу ссылаются | метка строфы, например `"chorus"` |
| `type` | нет | `verse` (по умолчанию) · `chorus` · `bridge` · `intro` · `outro` |
| `lines` | одно из двух | Строка[] |
| `ref` | одно из двух | `id` ранее объявленной строфы: показать её ещё раз |

### Строка

| Поле | Обяз. | Смысл |
|---|---|---|
| `<lang>` | да | оригинал строки |
| `<другой язык>` | желательно | перевод. Строку без перевода загрузка принимает с предупреждением |
| `lit` | нет | Локализованное: **дословный** перевод, когда художественный далёк от буквального |
| `phrases` | нет | Фраза[]: единицы для изучения и повторения |
| `words` | нет | Слово[]: ручной разбор слов. Слова без разбора приложение связывает со словарём само |
| `note` | нет | Локализованное: грамматика, идиома, контекст |
| `t` | нет | число секунд от начала аудио. Зарезервировано под караоке (BL-14), сейчас не используется |

### Фраза

Кусок строки, который стоит выучить целиком. Именно фразы попадают в «фразу дня» и в повторение.

| Поле | Обяз. | Смысл |
|---|---|---|
| `<lang>` | да | текст фразы, **дословно входящий в строку** (без учёта регистра) |
| `<другой язык>` | да, ≥ 1 | перевод |
| `note` | нет | Локализованное: пояснение |

### Слово

| Поле | Обяз. | Смысл |
|---|---|---|
| `<lang>` | да | форма слова, как она стоит в строке (`tienen`) |
| `<другой язык>` | нет | перевод в этом контексте |
| `lemma` | нет | словарная форма (`tener`). По ней слово связывается с частотным словарём |
| `pos` | нет | `verb` · `noun` · `adj` · `adv` · `pron` · `prep` · `conj` · `det` · `num` · `intj` |

## Правила проверки при загрузке

Ошибки блокируют загрузку, предупреждения нет. Сообщение всегда указывает путь (индексы с нуля, как в редакторе) и цитирует проблемный текст: `stanzas[1].lines[2].phrases[0]: фраза «…» не найдена в строке «…»`. Сообщения — на языке интерфейса (RU/EN/ES).

**Ошибки:**
0. Файл больше 1 МБ (песня — единицы КБ, это почти наверняка не тот файл) или не JSON: для JSON сообщение называет строку и столбец.
1. Файл не соответствует схеме: нет обязательного поля, неизвестный ключ, неверный тип.
2. В названии, строке, фразе или слове нет ключа оригинала (`lang`).
3. У фразы нет ни одного перевода.
4. Фраза или слово не входят дословно в текст своей строки (без учёта регистра и формы записи Unicode: «ñ» одним символом и составным — одно и то же).
5. `ref` ссылается на строфу, не объявленную выше, или у строфы одновременно `lines` и `ref`, или нет ни того, ни другого.
6. Повторяющийся `id` строфы.

**Предупреждения:**
1. Строка без перевода.
2. Перевод есть не на всех языках, которые используются в остальных строках файла.

## Обновление и прогресс

- Загрузка с существующим `id` заменяет текст после подтверждения; в подтверждении — сколько фраз останется, добавится и уйдёт. Тот же текст в другом форматировании — «без изменений», без вопроса. Тексты на устройстве общие для всех профилей (`D-17`).
- Прогресс фразы привязан к паре «`id` текста + нормализованный оригинал фразы» (Unicode NFC, нижний регистр, пробелы внутри схлопнуты, пробелы и пунктуация по краям убраны; `phraseKey` в `app/src/features/texts`). Исправил перевод — прогресс сохраняется. Изменил оригинал фразы — это новая фраза, старая уходит из повторения.

## Приватность

- `license: "personal"` — чужой текст для личного пользования; в репозитории — в `content/private/` (в git, D-41) и в поставке PWA (D-43). Загруженная вручную копия с тем же id не перекрывает версию из поставки.
- В `content/texts/` — только `public-domain` и `own`; личные тексты — в `content/private/`, тоже в поставке (`D-43`).

## Эволюция формата

- Новые **необязательные** поля добавляются без смены `version`. Приложение игнорирует незнакомые поля только внутри объектов `ext` (зарезервировано), остальные незнакомые ключи — ошибка, чтобы опечатки не терялись молча.
- Несовместимое изменение → `version: 2` + конвертер из v1.
