## Контекст / зачем
Формат урока звучания и два урока (ES-P1 алфавит, ES-P3 c/z/qu, g/j, h) есть, но открыть их негде: путь уроков знает только слова. Ученик хочет с первых дней слышать буквы и звуки, читать вслух и диктовать имя или email по буквам (`D-9`).

## Цель
Вкладка «Уроки» ведёт и в уроки звучания; плеер проводит через буквы/правила и упражнения `pairs`, `read`, `dictation`, `spell`.

## Объём
**Входит:**
- Раздел «Звучание» во вкладке «Уроки» (по языку, по `order`, статусы пройден / открыт), вход `/sounds/:id`.
- Знакомство: алфавит (буква, название, IPA, нажатие — звук) и правила чтения (заголовок, текст, IPA, примеры с озвучкой).
- Упражнения: `pairs` — слышит одно слово, выбирает написанное; `read` — видит слово, читает, слушает, сам отмечает «получилось / ещё раз»; `dictation` — слышит и печатает (без ударения — с подсказкой); `spell` — видит слово, называет буквы, затем сверяет с названиями букв (для `.`, `@`, `-`, `_` — «punto/arroba/guion/guion bajo», «dot/at/dash/underscore»).
- Звук: записанный файл `audio` из `content/audio/…`, если он есть в сборке, иначе голос устройства (`D-13`); общая очередь с одним повтором ошибки, как у слов.
- Итог: прохождение пишется в `lesson_progress`, активность `lesson` (цель дня и серия).

**Не входит:** сами записи аудио, новые уроки звучания (ES-P2…, EN-P*), карточки повторения из упражнений звучания.

## Критерии приёмки
- **AC-1.** Во вкладке «Уроки» для языка с уроками звучания есть раздел «Звучание»; нажатие открывает плеер, пройденный урок помечен.
- **AC-2.** Урок с алфавитом показывает буквы; нажатие на букву/пример/правило воспроизводит звук (запись или голос); без звука кнопок нет.
- **AC-3.** `pairs` и `dictation` засчитывают верный ответ (диктант без ударения — с подсказкой), ошибка возвращает задание в конец один раз.
- **AC-4.** `spell` показывает названия букв слова в порядке; email включает `punto` / `arroba`; `read` и `spell` оцениваются самоотметкой.
- **AC-5.** Итог показывает результат и сохраняет прохождение; состояния: загрузка, неизвестный урок, ошибка с повтором.

## Подход
`features/lessons/player/sound.ts` (чистые функции: задания по упражнениям, названия букв), `Practice` обобщается по типу задания, `audio.ts` (запись → голос), UI-компонент `SoundTask`, страница `SoundLessonPage`, раздел во вкладке «Уроки».

## Тесты
Класс риска: К2 — unit: сборка заданий из упражнений, `spellNames` (буквы, диакритика, символы), пары в обе стороны, сверка диктанта, обобщённая очередь; К3 (страницы) — ручной смоук.

## Ключ к корректности / риски
`spell`: названия берутся из алфавита урока, а у уроков без `letters` — из алфавита того же языка (иначе `es-sound-03` не продиктует email); буква с диакритикой (`ñ`, `í`) — отдельное название или базовая буква, регистр не важен.
