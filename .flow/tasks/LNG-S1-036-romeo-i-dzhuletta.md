## Цель
Запрос заказчика: добавить в изучение английского «Ромео и Джульетту» — не всю пьесу, а ключевые отрывки, с разбором языка.

## Критерии приёмки
- **AC-1.** 7 отрывков по порядку пьесы: пролог (Пролог), сцена на балконе (II.2), «fortune's fool» (III.1), «Gallop apace» (III.2), соловей и жаворонок (III.5), «Here will I remain» (V.3), последние строки князя (V.3). У каждого — построчный перевод RU, «дословно» там, где перевод далёк от текста, пояснения архаизмов и инверсий, фразы для повторения, `see` на темы EN-N.
- **AC-2.** Формат: вид `play`, поле строфы `speaker`; схема, валидатор, тесты.
- **AC-3.** Чтение и урок показывают, кто говорит; урок `/songs/:id` и кнопка «Урок по тексту» — у любого текста; раздел «Песни и стихи» во вкладке «Уроки» включает стихи и пьесы.
- **AC-4.** Отрывок 6 с присланным заказчиком переводом («Здесь вечный отдых для меня начнётся…») — в `content/private` (`personal`): автор перевода не указан.

## Проверки
`npm run typecheck`, `npm run lint`, `npm run test` — зелёные. Браузерный смоук (Playwright, 390×844): библиотека с фильтром «Пьеса», чтение сцены на балконе с метками персонажей, урок по отрывку 6 — без ошибок в консоли.
