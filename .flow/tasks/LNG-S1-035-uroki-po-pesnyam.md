## Цель
Запрос заказчика: по своим песням — уроки и разборы, встроенные в процесс обучения. До этого песню можно было только читать и отправлять фразы в повторение по одной.

## Критерии приёмки
- **AC-1.** У любой песни библиотеки (поставка и загруженная своя) есть урок `/songs/:id`: «о песне» (заметка, правила) → разбор строф (перевод, дословно, пояснение строки, фразы с пояснениями) → практика по фразам (вставить фразу в строку, собрать фразу по переводу) → итог.
- **AC-2.** На итоге: прогресс `song:<id>`, все фразы песни — в повторении FSRS, ссылка на текст, правила песни, «Дальше» по пути.
- **AC-3.** Песни в процессе: раздел «Песни» во вкладке «Уроки»; на «Главной» — «Песня для разбора» (с перевесом пройденных правил); в итоге темы грамматики и карточке правила — «Правило в песнях»; на странице текста — «Урок по песне».
- **AC-4.** Формат текста: необязательное поле `see` (темы грамматики); валидатор, схема и тест контента (отсылки ведут на темы языка текста).
- **AC-5.** 9 песен `content/private/` размечены: `see`, пояснения к ключевым строкам с отсылками EN-N.

## Что сделано
- Урок строится из самого текста — отдельных файлов уроков нет, поэтому урок есть у любой песни, в том числе загруженной на устройство.
- Личные песни `content/private/` входят в поставку (D-43): уроки по ним есть сразу, без загрузки файлов.
- Практика: до 8 фраз, «вставь» на каждую (варианты — другие фразы песни), «собери» — для фраз из нескольких слов.
- «Песня для разбора»: счёт = пройденные темы `see` − непройденные; новичку — простые песни без правил.

## Не вошло
- Аудио песни и караоке (BL-14); покрытие песни словами (BL-9).
- Разметка `see` у 16 текстов поставки.
