## Цель
Вкладка «Словарь»: язык (из изучаемых языков профиля) × список (глаголы, существительные, прилагательные, наречия, «мои слова»), слова по частоте с переводом, поиск по слову, форме и переводу, отметка «в мои слова» — своя у каждого профиля, офлайн.

## Объём
**Входит:** загрузка словарей приложения (ленивые чанки, офлайн через оболочку), чистые функции каталога (списки, поиск без учёта регистра и ударений), стор «мои слова» на IndexedDB (миграция v3, стор ученика — в копии и каскадном удалении, D-18), экран с состоянием в URL, i18n.

**Не входит:** карточка слова (следующая задача), прогресс изучения (BL-5 — счётчик «выучено» подключится к повторению), озвучка.

## Критерии приёмки
- **AC-1.** Во вкладке «Словарь» выбираются язык (только изучаемые профилем) и список; слова идут по рангу с переводом, у существительных ES — артикль (el/la), неправильные глаголы отмечены.
- **AC-2.** Поиск находит по лемме, форме и русскому переводу, без учёта регистра и ударений («ano» находит «año», «pienso» — «pensar»).
- **AC-3.** Звёздочка добавляет слово в «мои слова» активного профиля; у другого профиля — свой список; переживает перезапуск; попадает в резервную копию и удаляется вместе с профилем.
- **AC-4.** Язык, список и запрос — в URL: обновление страницы и «назад» возвращают тот же вид.
- **AC-5.** Работает без сети (словари в офлайн-оболочке).

## Решения
- **D-1. Прогресс «выучено N из M» — с BL-5**: без интервального повторения считать нечего; экран показывает размер списков, место под счётчик — в заголовке списка.
- **D-2. «Мои слова» — стор ученика `saved_words`** (ключ `[profileId, key]`, индекс `profileId`), `key` — ключ прогресса слова `word:<lang>:<id>` (D-19): статья может переименоваться только с миграцией прогресса.
- **D-3. Словари — в сборке приложения**, ленивыми чанками по файлу: контент поставляется с приложением (D-5), офлайн — через оболочку сервис-воркера.
- **D-4. Поиск без ударений и ñ** (ano → año): ученик часто не может набрать знак; точное совпадение леммы — выше.

## Тесты
Класс риска: **К2** — каталог (списки, поиск, ранжирование), стор «моих слов»; **К1** — миграция v3 (данные учеников сохраняются), «мои слова» в копии и каскаде. Экран — К3, ручной смоук по AC.

## Ключ к корректности / риски
Миграция v3 не должна трогать сторы v1–v2. «Мои слова» обязаны перезагружаться при смене профиля — иначе один член семьи увидит звёздочки другого.
