## Цель
Касание слова в словаре открывает карточку: слово с артиклем, транскрипция, перевод, озвучка слова и примеров голосом устройства, формы (спряжение ES по лицам и временам, формы EN, мн. число, род прилагательных), пример по темам, пояснение, пара во втором языке со ссылкой на её карточку, «в мои слова».

## Критерии приёмки
- **AC-1.** Из списка и из поиска словаря касание слова открывает его карточку; «назад» возвращает в тот же вид списка.
- **AC-2.** Карточка показывает всё, что есть в статье: артикль, транскрипцию, перевод, неправильность, пояснение, примеры с переводом и темой.
- **AC-3.** Формы показаны таблицей: у глагола ES — времена по шести лицам (yo … ellos/ustedes), герундий и причастие; у остальных — подписанные формы.
- **AC-4.** Кнопка озвучки произносит слово и каждый пример голосом устройства на языке слова; если голоса для языка нет — кнопки нет.
- **AC-5.** Пара открывает карточку слова во втором языке.
- **AC-6.** Звёздочка «в мои слова» работает так же, как в списке.

## Решения
- **D-1. Озвучка — Web Speech API** (`D-13`), фасад `shared/native/speech.ts`; голос выбирается по языку: точное совпадение региона по умолчанию (es-ES, en-US) → любой того же языка → нет озвучки. Нативные сборки (BL-13) — тот же фасад.
- **D-2. Маршрут `/dictionary/:lang/:id`** вне вкладок, с кнопкой «назад»: карточке нужен весь экран; состояние списка живёт в URL списка (D-26) и восстанавливается по «назад».
- **D-3. Подписи времён и лиц**: местоимения лиц — данные языка (yo, tú…), названия времён — i18n.

## Ключ к корректности / риски
Карточка по несуществующему id (устаревшая ссылка, переименование в выверке) — понятное «слово не найдено», а не пустой экран. Клик по звёздочке в строке списка не должен открывать карточку.
