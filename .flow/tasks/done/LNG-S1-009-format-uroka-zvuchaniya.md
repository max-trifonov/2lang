## Контекст / зачем
Урок звучания (curriculum): алфавит и названия букв, правила чтения, звуки, ударение; механики «услышь и выбери» (минимальные пары *pero / perro*), «прочитай сам», диктант, «продиктуй по буквам». После темы правило чтения живёт в карточке каждого слова, где оно встречается (`rules` словаря). Звуки и буквы — записанное аудио, слова — голос устройства (`D-13`).

## Цель
Вид `sound` в формате урока v1: буквы, правила чтения с id, упражнения четырёх механик, ссылки на записанное аудио; сверка `rules` словаря с правилами уроков; пример ES-P1 (алфавит) и ES-P3 (c / z / qu, g / j, h).

## Объём
**Входит:** вид `sound` (буквы, правила, упражнения `pairs`, `read`, `dictation`, `spell`), поле `code` (связь с программой: `ES-P3`, `ES-6`), трек пути по виду, путь к аудио `audio/<lang>/…`; набор: уникальность id правил, разрешение `rules` словаря, существование аудиофайлов (в тесте контента); схема, пример, сообщения.

**Не входит:** запись аудио (BL-18), плеер (BL-18), вид `grammar` (следующая задача).

## Критерии приёмки
- **AC-1.** Примеры ES-P1 и ES-P3 проходят проверку вместе со словарём; ссылки `rules` словаря разрешаются.
- **AC-2.** Правила-ошибки вида `sound` дают ошибку с путём и сообщением RU/EN/ES; упражнение не своего вида — ошибка.
- **AC-3.** Повтор id правила между уроками и ссылка словаря на неизвестное правило находятся при проверке набора; ссылка на несуществующий аудиофайл роняет тест контента.
- **AC-4.** Уроки слов проверяются как раньше; `topic` обязателен только у них.

## Решения
- **D-1. Трек пути = тема для урока слов, вид для звучания и грамматики**: `order` уникален в паре язык × трек; у звучания и грамматики `topic` нет.
- **D-2. id правила чтения глобальный** (`es-c-before-e-i`): на него ссылаются статьи словаря; повтор между уроками — ошибка, неразрешённая ссылка словаря — предупреждение (урок с правилом могут ещё не написать).
- **D-3. Слова в упражнениях звучания — строки, не ссылки на словарь**: минимальные пары и диктант берут любые слова (*perro*, *carro*), а не только частотные.
- **D-4. Аудио — относительный путь `audio/<lang>/….mp3|ogg|m4a`** от `content/`; у слов аудио нет — голос устройства (`D-13`).

## Ключ к корректности / риски
id правила — ключ связи со словарём: переименование правила молча отрывает подсказку от слов — поэтому неразрешённая ссылка видна в проверке набора. Пара в `pairs` — ровно два разных слова, иначе «услышь и выбери» не из чего выбирать.

## Итог реализации
**Сделано.** Спецификация `.flow/lesson-format.md` дополнена видом `sound`, полем `code` и треком пути (D-21). Валидатор: ключи тела по виду, `topic` только у слов (`topic_not_allowed` у звучания), буквы, правила чтения (id, примеры с оригиналом, `ipa`, аудио), упражнения звучания (`pairs` — ровно два разных слова, `read`, `dictation`, `spell`), упражнение чужого вида — ошибка, путь аудио по шаблону. Набор: место в треке (тема или вид), повтор id правила между уроками, ссылки `rules` словаря на правила уроков (предупреждение). Схема: условия по виду (`allOf`/`if`), определения букв, правил и упражнений звучания. Примеры: `es-sound-01` (27 букв с названиями, ñ, правило `es-n-tilde`, `spell`/`pairs`/`dictation`), `es-sound-03` (5 правил: c перед e/i, z, qu, g перед e/i и gu/gü, немая h; `pairs`/`read`/`dictation`). Тест контента проверяет, что аудиофайлы из уроков существуют.

**Проверка.** typecheck, lint, 318 тестов; сверка схемы и валидатора — 8 фикстур слов и 7 звучания.

**Отклонения.** Найдено своим тестом: место в пути считалось по `topic`, и все уроки звучания одного языка попадали бы в один ключ `undefined` — переведено на `trackOf`. Из примера словаря убрана ссылка `aquí → es-written-accent`: урока ES-P5 ещё нет (вернётся с ним).

**Грабли.** Сообщения i18n с необязательным параметром (`{other}`) хрупкие — передавать параметр всегда (в файле — путь первого, в наборе — имя файла).

**Долг.** Нет. Записанное аудио — отдельная строка BL-18.
