## Цель
Ученик открывает повторение языка, проходит карточки, срок которых пришёл, заданиями по лестнице «узнать → услышать → вспомнить»; каждый ответ пересчитывает срок карточки по FSRS.

## Объём
**Входит:** маршрут `/review?lang=`; сессия до 20 карточек, самые просроченные первыми; задание по зрелости карточки: новая или стабильность < 3 дней — «узнать», < 10 — «услышать» (нет голоса — «узнать»), иначе «вспомнить»; оценка: ошибка — «Забыл», верно с подсказкой написания — «Трудно», верно — «Хорошо»; ошибочное задание повторяется в конце один раз без повторной оценки; итог (сколько верно с первого раза, когда ближайшее повторение); на «Главной» у языка — «К повторению: N» и вход.
**Не входит:** упражнения «применить» (фразы — с песнями и фразами BL-5/BL-6); повторение по разделам и фильтры; оценка «Легко» (кнопки самооценки); напоминания.

## Критерии приёмки (AC-1…N)
- **AC-1.** «Главная» показывает у языка число карточек к повторению и кнопку; при нуле — «На сегодня всё».
- **AC-2.** Сессия предлагает карточки к повторению выбранного языка, не более 20, самые просроченные первыми; задания подбираются по зрелости карточки.
- **AC-3.** Ответ сразу меняет карточку: ошибка — срок завтра и больше провалов, верный — срок дальше; результат сохраняется до конца сессии (выход ничего не теряет).
- **AC-4.** Ошибочное задание возвращается в конце сессии один раз и не оценивается повторно.
- **AC-5.** Итог показывает долю верных с первого раза; после сессии на «Главной» счётчик уменьшился.
- **AC-6.** Нет карточек к повторению — понятное пустое состояние.

## Решения
- **D-1. Автооценка по ответу**: ошибка — 1, подсказка написания — 2, верно — 3 (кнопок «легко / трудно» нет — меньше действий, привычка важнее точности подбора).
- **D-2. Оценка сразу при ответе**, а не в конце сессии: выход посреди сессии сохраняет сделанное.
- **D-3. Одна сессия — один язык** (как урок): `?lang=` обязателен, без него — первый язык профиля.
- **D-4. Общие задания с плеером**: фабрики `recognize` / `hear` / `recall` выносятся из `buildPractice` и используются обоими.

## Ключ к корректности / риски
Повтор после ошибки не должен второй раз сдвигать срок карточки — иначе она «выучена» повтором. Задание «услышать» на карточке без голоса не должно ломать сессию.
