## Контекст / зачем
brief: топ-500 глаголов, топ-1000 существительных, топ-200 наречий и прилагательных для EN и ES. Источник — wordhoard v0.1.0 (`D-24`): лемма, часть речи UD, род, ранг по субтитрам. Автоматическая разметка даёт шум: дубли VERB/AUX, формы вместо лемм (buen, gran), варианты написания (sólo/solo), ошибки разметки (dio как прилагательное, wasn как существительное), грубая лексика. Каркас — то, к чему ИИ-черновик (D-25) пишет переводы и примеры.

## Цель
Воспроизводимый импорт: скрипт + выверяемый конфиг → каркас топ-списков в `content/frequency/` (лемма, часть речи, ранг в части речи, род, ранг источника) и отчёт отфильтрованного.

## Объём
**Входит:** чистые функции импорта (маппинг частей речи, слияние дублей, алиасы, стоп-лист, ранги внутри части речи, отбор топов) с тестами; CLI `npm run content:frequency -- --src <каталог wordhoard>`; конфиг `content/frequency/config.json`; каркас CSV по языку × списку; `NOTICE.md` с атрибуцией; выверка стоп-листа по верхушкам списков.

**Не входит:** переводы, примеры, формы и флаг `irregular` (ИИ-черновик, следующая задача); экран «Словарь».

## Критерии приёмки
- **AC-1.** `npm run content:frequency` из скачанного wordhoard воспроизводит те же CSV (детерминированно).
- **AC-2.** В каркасе нет дублей лемм в списке, форм-вместо-лемм из алиасов, слов стоп-листа; ранги в части речи 1…N без дыр; у существительных ES есть род (без рода — в отчёт, не в список).
- **AC-3.** Размеры: глаголы 500, существительные 1 000, прилагательные 200, наречия 200 — для каждого языка.
- **AC-4.** Отчёт перечисляет, что и почему отфильтровано (для выверки автором).

## Решения
- **D-1. «Топ-200 наречий и прилагательных» — по 200 каждого**: ранги в словаре — внутри части речи (`D-19`), раздельные списки проще считать «прилагательные: 37/200».
- **D-2. VERB и AUX — один список глаголов**: be, have, can, ser, estar — самые нужные глаголы, разметка AUX для изучения не важна; дубль лемм сливается по лучшему рангу.
- **D-3. Стоп-лист — данные с причиной** (`vulgar`, `not-lemma`, `mistagged`, `fragment`), а не код: выверка автором — правка конфига, причины видны в отчёте.
- **D-4. Каркас — CSV в `content/frequency/`**, не формат словаря: в нём нет обязательных переводов; производные данные CC BY-SA с `NOTICE.md`.
- **D-5. Существительное ES без рода не входит в топ**: формат требует род (`D-19`), а пустой род в источнике — почти всегда ошибка разметки (tal).

## Тесты
Класс риска: **К2** — функции импорта (слияние, алиасы, стоп-лист, ранги, отбор, детерминизм) unit-тестами на маленьких фикстурах CSV. Сам каркас — проверка инвариантов AC-2/AC-3 тестом контента.

## Ключ к корректности / риски
Ранг каркаса станет рангом статьи, а id статьи = лемма — ключ прогресса: ошибка в лемме (форма вместо леммы) дойдёт до прогресса пользователей. Поэтому алиасы применяются до слияния дублей, а отчёт показывает каждое слияние.

## Итог реализации
**Сделано.** `app/scripts/lib/frequency.mjs` — чистые функции импорта (разбор CSV по RFC 4180, VERB+AUX → глаголы, алиасы до слияния, стоп-лист по «часть_речи:лемма» и «лемма», правило id словаря, слияние дублей по лучшему рангу, род обязателен у существительных ES, поправки рода после отбора, ранги 1…N в части речи); CLI `npm run content:frequency -- --src <каталог>`. `content/frequency/`: конфиг выверки (42+ алиаса ES, стоп-лист ES/EN с причинами `name`, `fragment`, `mistagged`, `not-lemma (participle)`, `subtitle annotation`, `vulgar`, `sensitive`; 38 поправок рода ES), каркас 8 списков (глаголы 500, существительные 1 000, прилагательные 200, наречия 200 × EN, ES), отчёты для выверки, NOTICE с атрибуцией CC BY-SA.

**Проверка.** Выверка — просмотр всех 3 800 лемм; повторный импорт побайтно совпадает (md5). Тесты: 9 unit на функции импорта, инварианты каркаса (размеры, ранги без дыр, уникальность, правило id, нет стоп-слов и форм-алиасов, род у ES-существительных) — 31 зелёный.

**Отклонения.** Добавлены поправки рода (`genders`): источник ошибается в роде (fin/f, calor/f) и не знает общего рода (estudiante, testigo — `mf`). Сырые данные wordhoard в репозиторий не кладутся — только каркас и конфиг.

**Грабли.** Субтитры для глухих дают «слова»-ремарки (sigh, gasp, applause, narrator) — отдельная причина в стоп-листе. Причастия под ADJ: оставлены те, что работают как прилагательные (cansado, casado, perdido), убраны чисто глагольные (hecho, visto, dicho).

**Долг.** Нет.

**Проверка AC:** AC-1 — повторный импорт побайтно совпал (md5) · AC-2 — frequency-content.spec: уникальность, id, стоп-лист, алиасы, род ES · AC-3 — frequency-content.spec: 500/1000/200/200 × EN, ES · AC-4 — report.es.md, report.en.md
