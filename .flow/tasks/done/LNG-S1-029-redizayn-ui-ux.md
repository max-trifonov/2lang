## Контекст / зачем
Интерфейс остался на дефолтах шаблона: системный шрифт, синие кнопки, одинаковые белые карточки. Английский и испанский выглядят одинаково, хотя главный риск продукта — языки сливаются в кашу. Заказчик просит современный вид с акцентами, который помогает восприятию и запоминанию.

## Цель
Визуальная система «два голоса»: у каждого языка свой цвет, иностранный текст набран отдельным шрифтом, родной язык — тихим. Главные экраны («Сегодня», «Уроки», плеер, повторение, словарь, карточка слова) перестроены вокруг этой системы и удобны одной рукой.

## Объём
**Входит:**
- токены: палитра (бумага, чернила, EN — кобальт, ES — шафран, награда, род сущ.), шрифты Onest (интерфейс, кириллица) и Fraunces (иностранный текст), офлайн из бандла;
- тинт по языку: контейнер `data-lang` задаёт `--tint*`, компоненты кита берут его;
- кит: кнопка (тинт, ghost), чип, карточка, список, поле, нижняя навигация;
- «Сегодня»: кольцо цели дня, серия, фраза дня в цвете языка, карточки языков (повторение первым — интервальное повторение важнее нового);
- «Уроки»: путь-таймлайн с узлами по статусам, текущий урок выделен;
- плеер урока и повторения: крупная карточка слова, подсветка слова в примере, артикль в цвете рода, кнопки внизу экрана (зона большого пальца), заметная обратная связь верно/неверно, итог с кольцом;
- словарь и карточка слова: иностранное слово шрифтом языка, «мост» к паре во втором языке в её цвете;
- тёмная тема не ломается; `prefers-reduced-motion` гасит анимации.

**Не входит:**
- новая логика уроков, повторения, путей; новые экраны;
- иконки PWA и сплэш;
- перенос правок кита в `templates-app` (долг, upstream-first).

## Критерии приёмки (AC-1…N)
- **AC-1.** Английский и испанский различимы без чтения подписи: бейдж, цвет акцентов и прогресса в уроке, повторении, карточке слова, путях — в цвете языка.
- **AC-2.** Слово и фраза на изучаемом языке набраны шрифтом Fraunces в цвете языка; перевод и объяснения — шрифтом интерфейса, приглушённо. Шрифты грузятся без сети.
- **AC-3.** В примере к слову (знакомство в уроке, карточка слова) само слово или его форма подсвечены.
- **AC-4.** У испанского существительного артикль окрашен по роду (м / ж).
- **AC-5.** «Сегодня»: прогресс цели дня — кольцо; по каждому языку видно, сколько слов ждут повторения и какой урок следующий, вход в одно касание.
- **AC-6.** «Уроки»: путь — вертикальная линия с узлами «пройден / знаком / следующий / открыт», следующий узел выделен.
- **AC-7.** В плеере кнопки «Проверить / Дальше» прижаты к низу экрана; после ответа виден блок верно/неверно с иконкой и правильным ответом.
- **AC-8.** Тёмная тема: текст и акценты читаемы (контраст ≥ 4.5:1 для текста).
- **AC-9.** `typecheck`, `lint`, `test` зелёные.

## Подход
1. Фича `features/language`: CSS-токены языков (`light-dark()`), `LangBadge`, утилита подсветки `highlightParts`.
2. Палитра темы и шрифты; тёмная тема поднимает primary до контраста с фоном.
3. Кит: тинт через `var(--tint, …)`.
4. Экраны по порядку: «Сегодня» → «Уроки» → плеер + задание → повторение → словарь → карточка слова → прочие (бейджи и шрифт языка).
5. Смоук в браузере на 390 px, светлая и тёмная темы.

## Тесты
Класс риска: К2 для `highlightParts` (чистая функция: какие слова примера подсвечивать) — unit; остальное К3 (отображение) — ручной смоук по AC.

| Вход | Ожидание |
|---|---|
| «Soy desarrollador», лемма ser, формы soy… | подсвечено «Soy» |
| «I booked a room», лемма book | подсвечено «booked» (основа) |
| «Tengo que reservar», лемма tener que | подсвечены «Tengo», «que» |
| текст без слова | ни одной подсветки, текст цел |
| знаки препинания, регистр, ударения | части склеиваются в исходный текст без потерь |

## Ключ к корректности / риски
- Тинт не должен красить «чужой» язык: фраза дня из ES на экране с EN-профилем — в цвете ES (тинт по языку контента, не профиля).
- Контраст оранжевого ES на белом низкий — для текста отдельный тёмный «ink»-оттенок.
