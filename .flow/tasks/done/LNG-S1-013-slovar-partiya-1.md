## Цель
Статьи словаря для топ-100 каждого из 8 списков (глаголы, существительные, прилагательные, наречия × EN, ES) и для слов, на которые ссылаются уроки: перевод на русский под основное значение, 2 бытовых примера по темам (`travel`, `it`, `daily`), формы, `irregular`, пары EN↔ES; пример формата из LNG-S1-007 заменяется.

## Критерии приёмки
- **AC-1.** Словари проходят валидатор без ошибок и предупреждений; уроки — вместе с ними.
- **AC-2.** Ранг, часть речи и род каждой статьи совпадают с каркасом `content/frequency/`; id = лемма каркаса.
- **AC-3.** Каждая статья черновика помечена `ext.draft: true` (D-25); тест показывает число черновиков.
- **AC-4.** Правила чтения ES (`rules`) ссылаются только на правила уроков звучания и проставлены по написанию.

## Решения
- **D-1. Правильные формы — по правилам в сборке, неправильные — явно.** Спряжение ES (presente, pretérito, герундий, причастие) и множественное число выводятся детерминированно; исключения пишутся руками — так не появляются выдуманные формы.
- **D-2. Пары EN↔ES — только если пара есть в наборе**: иначе предупреждение `pair_not_found` (`D-19`).
- **D-3. Примеры нейтральные**: у частотных из субтитров «matar», «kill», «disparar», «shoot» — бытовые и IT-значения («this bug is killing me», «disparar un evento»).

## Ключ к корректности / риски
Черновик ИИ — не выверенный контент: пометка `draft` обязана остаться, пока автор не проверил слово. Пример должен содержать лемму или одну из форм — иначе предупреждение и слово «не про пример».
