## Контекст / зачем
Урок грамматики (curriculum): паттерн (3–4 бытовых примера из изученных слов) → правило на одном экране (формула, короткая таблица, 1–2 фразы, для времён — линия времени) → мост к другому языку и русскому (если пара полезна) → практика (трансформер предложения: отрицание, вопрос, прошедшее/будущее, вежливая форма; выбор формы по контексту; вставить форму; собрать из блоков) → «применить» (своё предложение по шаблону, сверка с образцом). Правило попадает в справочник, предложения-трансформации — в повторение.

## Цель
Вид `grammar` в формате урока v1: спецификация, валидатор, схема, пример ES-6 («tener que + инфинитив»).

## Объём
**Входит:** паттерн, правило (формула, текст, таблица, линия времени), мост, слова-условие открытия темы (ссылки на словарь), упражнения `transform`, `choose`, `fill`, `build`, `compose`; набор — слова в словаре; схема, пример, сообщения.

**Не входит:** плеер, справочник, встраивание в путь (BL-10), контент тем.

## Критерии приёмки
- **AC-1.** Пример ES-6 проходит проверку вместе со словарём; уроки других видов — как раньше.
- **AC-2.** Правила-ошибки вида `grammar` (таблица не той формы, повтор формы в трансформере, ответ не из вариантов, мост на язык урока…) дают ошибку с путём и сообщением RU/EN/ES.
- **AC-3.** Слово-условие, которого нет в словаре, находится при проверке набора.

## Решения
- **D-1. Формы трансформера — закрытый список видов предложений** (curriculum): `negative`, `question`, `wh-question`, `imperative`, `polite`, `past`, `future`; база — утверждение в оригинале упражнения; повтор формы — ошибка.
- **D-2. Линия времени — данные, а не картинка**: отрезки `from`/`until` из `past` · `now` · `future` с подписью; рисует плеер, в обеих темах.
- **D-3. Мост — список пар на другие языки**: язык моста ≠ язык урока, примеры на языке моста с переводом; показывается, только если есть.
- **D-4. `words` у грамматики — условие открытия темы**, а не новые слова: ссылки на словарь, без предупреждений о составе.
- **D-5. Таблица — `head` + `rows` одинаковой ширины**: справочник рендерит её как есть.

## Ключ к корректности / риски
Ответ `choose` обязан быть среди вариантов, иначе упражнение нерешаемо. В трансформере ответы — полные предложения на языке урока: сверка — как у `translate` (без регистра и знаков по краям), иначе ученик ошибётся на пунктуации.

## Итог реализации
**Сделано.** Спецификация `.flow/lesson-format.md` — вид `grammar` (D-22). Валидатор: тело грамматики (паттерн с предупреждением о размере, правило — текст, формула, таблица одной ширины, линия времени, мост на другой язык с примерами на языке моста), упражнения по типу с полями своего типа (`transform` — формы из закрытого списка без повторов, `choose` — один пропуск, ≥ 2 разных варианта, ответ среди них, `fill`/`build` — общие с уроком слов, `compose` — задание и образец); набор — слова-условие в словаре. Схема: `grammarRule`, `bridge`, `grammarExercise`, условия по виду. Пример `content/lessons/es-grammar-06.json` (ES-6 tener que + инфинитив: 3 примера, таблица 6 лиц, линия времени, мост к have to, 5 упражнений).

**Проверка.** typecheck, lint, 354 теста; сверка схемы и валидатора — фикстуры слов, звучания (7) и грамматики (9).

**Отклонения.** Тест выявил конфликт контракта: поле `to` двухбуквенное и разбиралось как язык (тонганский). Введено правило D-23 — имена полей не бывают двухбуквенными; переименованы `to` → `into` (трансформер), `to` → `until` (линия времени) и в словаре `tr` → `translations` (формат опубликован сегодня, внешнего контента нет). Для `choose` с одним вариантом — свой код `options_count` вместо «пусто».

**Грабли.** Цепочка `sed … && grep … && python3 …`: если `sed` не нашёл строку после prettier, `grep` возвращает 1 и правка кода молча не выполняется — правки делать скриптом с `assert` по якорям.

**Долг.** Нет.
