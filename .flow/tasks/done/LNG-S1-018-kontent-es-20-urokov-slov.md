## Контекст / зачем
Плеер готов, но в испанском один урок — проверить привычку «несколько уроков в день» не на чем. Словам уроков нужны статьи словаря, а сборка партии 1 перезаписывает словарь целиком (TD-4).

## Цель
В испанском 20 уроков слов: 10 «путешествия» (с уже существующим es-travel-01) и 10 «IT», каждый — 3–4 новых слова, фраза дня, мини-правило, 3–4 упражнения; недостающие слова добавлены в словарь сборкой в режиме слияния, не трогающей существующие статьи.

## Объём
**Входит:**
- Сборка словаря `content/drafts/build.py`: исходники из всех `batch-*/`, режим слияния по умолчанию (новые статьи добавляются, существующие — байт в байт), полная пересборка — только флагом `--rebuild`.
- Партия 2 (`batch-2/`): 23 существительных и 2 глагола для уроков, ИИ-черновик с `ext.draft`.
- Уроки `es-travel-02…10`, `es-it-01…10` (ИИ-черновик, `ext.draft`), приём «глагол-помощник + инфинитив» (necesitar / querer / poder / tener que / ir a + инфинитив) в правилах.

**Не входит:**
- Уроки EN (отдельная задача BL-4, после проверки «знаю / не знаю», `D-12`); уроки звучания и грамматики.
- Путь уроков по темам (экран); выверка черновиков — заказчик.

## Критерии приёмки (AC-1…N)
- **AC-1.** На «Главной» после прохождения урока предлагается следующий: путешествия 1→10, затем IT 1→10.
- **AC-2.** Каждый урок проходит в плеере от начала до итога; слова урока открываются карточками словаря.
- **AC-3.** Повторный запуск сборки словаря не меняет существующие статьи (выверка автора сохраняется) и добавляет только новые.
- **AC-4.** Все уроки и словари проходят проверки контента без ошибок и без предупреждений.

## Решения
- **D-1. Слияние по id статьи**: статья, уже лежащая в `content/dictionary/`, — источник истины, черновик её не трогает (в том числе пары и формы). Пара новой статьи — если вторая статья есть в итоговом словаре; обратные пары ES → EN — только у новых статей.
- **D-2. Порядок уроков — `order` без `requires`**: трек линейный, «следующий урок» (D-6 LNG-S1-017) идёт по `order`; `requires` — для будущих ветвлений.
- **D-3. Пометка черновика урока** — `ext.draft: true`, как у словаря (D-25): заказчик снимает при выверке.
- **D-4. Слова повторно не вводятся**: у каждого урока языка свой набор новых слов; знакомые слова свободно встречаются во фразах и упражнениях.

## Подход
Перенести `build.py` уровнем выше с режимом слияния; проверить, что слияние без новых данных даёт байт-в-байт тот же словарь. Написать `batch-2/es_noun.py`, `es_verb.py`; собрать. Написать 19 уроков; прогнать `npm run test` (валидатор уроков со словарём, предупреждения — тоже чинить); смоук в плеере на паре уроков.

## Тесты
Класс риска: контент — проверяется существующими тестами контента (`content.spec.ts` словаря и уроков: схема, валидатор, каркас); новых unit-тестов нет. Сборка (К1 для выверки автора) — проверка «слияние без новых данных = без изменений» и «повтор слияния = без изменений» вручную, итог — в «Итоге реализации».

## Ключ к корректности / риски
Слияние не должно переписывать существующие статьи даже косвенно (обратные пары, сортировка): сравнивать файлы до/после по статьям. Ответы `fill`/`translate` должны точно совпадать с формами словаря и правилами (ИИ легко ошибается в спряжении) — каждый ответ сверять с формами статьи.

**Сделано.** Сборка словаря перенесена в `content/drafts/build.py`: исходники из всех `batch-*/` (лемма — в одной партии), по умолчанию слияние по id (существующие статьи и заголовок файла не трогаются, пары и обратные пары — только у новых), `--rebuild` — полная пересборка (D-28, TD-4 закрыт). Партия 2 (`batch-2/`): 23 существительных (hotel, calle, billete, tren, estación, aeropuerto, vuelo, maleta, café, mesa, cuenta, mapa, proyecto, error, código, reunión, correo, archivo, ordenador, pantalla, tarea, cliente, versión) и 2 глагола (probar, guardar), `ext.draft`. 19 уроков ИИ-черновиком (`ext.draft`): `es-travel-02…10` (номер в отеле, близко/далеко, билет, поезд, аэропорт, чемодан, кафе, ресторан, «заблудился»), `es-it-01…10` (проект, ошибка, встреча, почта, компьютер, задача, клиент, переименование, команда, новая версия); по 4 слова (глагол + существительное + наречие/прилагательное), фраза дня, правило на RU/EN/ES с примерами, 4 упражнения (2 fill, build, translate). Приём «глагол-помощник + инфинитив»: necesitar (travel-02), querer (travel-04), poder (travel-07), tener que (it-03), ir a (it-10); также es fácil + инф., antes de + инф. (it-08).
