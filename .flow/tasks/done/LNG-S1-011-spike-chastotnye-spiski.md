## Цель
Выбрать открытые источники частотности (лемма + часть речи), понять лицензионные последствия и что придётся добыть отдельно.

## Критерии приёмки
- **AC-1.** Сравнение кандидатов по данным и лицензии; выбран основной источник и запасной.
- **AC-2.** Записаны последствия лицензии для файлов `content/dictionary/`.
- **AC-3.** Пробелы источника (переводы на русский, примеры по темам) вынесены вопросом заказчику с вариантами и дефолтом.

## Результат

| Источник | Что даёт | Лицензия данных | Годится |
|---|---|---|---|
| **wordhoard** v0.1.0 (2024-07, natema/wordhoard) | EN 85 тыс. / ES 57 тыс. лемм: часть речи (UD), род (ES 95 %), ранг и частота (OpenSubtitles-2018), формы (Wiktionary; спряжение ES — 18 %) | CC BY-SA 4.0 + NOTICE | **основной**: ровно наш формат (лемма + часть речи + ранг), разговорный корпус — как в целях brief |
| NGSL 1.2 (Browne и др.) | EN 2 809 лемм, отобраны экспертами по частоте и распределению | CC BY-SA 4.0 | сверка топов EN |
| FrequencyWords (hermitdave, OpenSubtitles) | словоформы с частотой, без лемм и частей речи | CC BY-SA 4.0 | запасной/сверка (сырьё того же wordhoard) |
| wordfreq (rspeer) | словоформы, смесь корпусов; проект заморожен | CC BY-SA 4.0 | нет: без лемм |
| wordfrequency.info (COCA, Davies) | леммы + части речи высокого качества | платная лицензия | нет |
| Tatoeba | пары предложений EN↔RU, ES↔RU | CC BY 2.0 FR (часть CC0), атрибуция автора предложения | возможный источник примеров (не по темам) |
| Wiktionary через kaikki.org | переводы на русский, формы, примеры | CC BY-SA | возможный источник переводов (много значений, нужна выборка) |

**Риски wordhoard:** молодой проект (одна версия, ~5 звёзд), автоматическая лемматизация spaCy — шум на неоднозначных словах, у ES мало спряжений. Снижение: берём снимок один раз (не живая зависимость), топы (500 глаголов, 1 000 существительных, 200 наречий и прилагательных) проходят ручную выверку, валидатор формата ловит структурные ошибки, спряжения неправильных глаголов — дописываются (`D-19`: чего нет, приложение не выдумывает).

**Лицензия:** файлы словаря, собранные из wordhoard/NGSL, — производные: `license: "cc-by-sa"` + `source` с атрибуцией; добавленные нами переводы и примеры в тех же файлах — тоже CC BY-SA. Код приложения не затрагивается (данные отдельно). Для поставки нужен экран атрибуции («Источники данных») — TD-3.

**Пробел:** ни один открытый источник не даёт русских переводов, подобранных под нужное значение, и бытовых примеров по темам «путешествия» и «IT» — это вопрос Q-6.

## Ключ к корректности / риски
ShareAlike распространяется на весь файл словаря — смешивать в одном файле данные с несовместимыми лицензиями (COCA, Oxford) нельзя.
