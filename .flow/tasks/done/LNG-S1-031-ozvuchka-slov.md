## Контекст / зачем
Озвучка шла только голосом устройства (D-13): на компьютере (Chromium/Electron на Linux) и в Android WebView голосов нет, и кнопка «озвучить» просто не появлялась — слово не услышать, задания «услышь» выпадали.

## Цель
По нажатию на иконку озвучки слово звучит на любом устройстве: записью из поставки, голосом устройства или онлайн-синтезом.

## Объём
**Входит:**
- записи всех лемм словарей EN/ES (Piper, открытые голоса), скрипт генерации `content/audio/words/build.py`;
- цепочка источников в `speak`: запись → голос устройства → онлайн-синтез; новое нажатие прерывает прежнее;
- кнопки `SpeakButton` / `SoundButton` видны всегда; ничего не прозвучало — тост;
- задания «услышь» доступны, если есть записи языка или голос устройства.

**Не входит:**
- записи примеров, фраз и строк текстов (звучат голосом или онлайн);
- записи звуков и букв уроков звучания (BL-18).

## Критерии приёмки (AC-1…N)
- **AC-1.** Кнопка озвучки видна всегда, независимо от голосов устройства.
- **AC-2.** Слово словаря звучит записью из поставки, в том числе офлайн (запись в precache).
- **AC-3.** Нет записи (пример, фраза) — голос устройства; нет голоса — онлайн-синтез; ничего не вышло — тост «не удалось озвучить».
- **AC-4.** Задания «услышь» в уроке, повторении и тренировке есть и на устройстве без голосов.
- **AC-5.** Запись есть у каждой леммы словаря; лицензии голосов задокументированы.

## Подход
Python-скрипт синтезирует леммы Piper-голосами (en_US-ljspeech-high — общественное достояние, es_ES-davefx-medium — CC0), срезает тишину и кодирует mp3 моно 48 кбит/с; имя файла — FNV-1a от нормализованной леммы, приложение считает тот же ключ. Записи подключаются eager-глобом `?no-inline` и попадают в precache сервис-воркера. `speak(text, lang, recorded?)` перебирает источники и возвращает, какой сработал.

## Тесты
Класс риска: К2. `audio.spec.ts`: ключ совпадает с Python (`casa` → `9f253efd`, `beautiful` → `1f951fd4`), не зависит от регистра/пробелов/NFC; у каждой леммы есть запись; чужой язык/слово → undefined. `speech.spec.ts`: URL онлайн-синтеза (язык, кодирование), пустой/длиннее 200 символов → null.

## Ключ к корректности / риски
Ключ записи в Python и TS должен совпадать — закреплено тестом. Онлайн-синтез отвечает 404 на запрос с чужим Referer — в `index.html` политика referrer `same-origin`. Голос устройства в Chrome может молчать без ошибки — отсекается таймаутом 2 с.
