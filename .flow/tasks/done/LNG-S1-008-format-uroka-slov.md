## Контекст / зачем
Урок слов по brief: разминка из повторения → новые слова (1 глагол + 1 существительное + 1 наречие или прилагательное, +1–2 по желанию) с примерами → фраза дня → мини-правило на примерах → практика → итог; лестница заданий «узнать → услышать → вспомнить → применить» (`D-7`). Слова, их переводы, формы и примеры уже лежат в словаре — урок должен на них ссылаться, а не копировать.

## Цель
Формат урока v1 с видом `words`: спецификация, схема, валидатор файла и набора уроков (со сверкой со словарём), пример урока ES в `content/lessons/`, проверяемый в `npm run test`. Виды `sound` и `grammar` добавят следующие задачи в тот же формат.

## Объём
**Входит:**
- общий заголовок урока (id, язык, вид, тема, место в пути, название, предпосылки) и вид `words`: новые слова (ссылки на словарь), фраза дня, мини-правило с примерами, ручные упражнения «применить»;
- валидатор файла и набора: уникальность id урока и места в пути, разрешение слов в словаре и предпосылок, предупреждения о составе урока;
- JSON Schema + сверка; пример: первый урок испанского на тему «путешествия».

**Не входит:**
- разминка и итог (собирает плеер из повторения и результатов урока), упражнения «узнать / услышать / вспомнить» — генерирует плеер из слов урока и словаря (`D-2`);
- плеер урока и путь (BL-4), виды `sound`, `grammar` (следующие задачи), контент ~20 уроков (BL-4).

## Критерии приёмки (AC-1…N)
- **AC-1.** Пример урока проходит проверку без ошибок вместе со словарём; уроки проверяются в `npm run test`.
- **AC-2.** Каждое правило-ошибка спецификации даёт ошибку с путём и сообщением на RU/EN/ES; предупреждения о составе урока не блокируют.
- **AC-3.** Слово урока, которого нет в словаре языка, повтор id урока, повтор места в пути, неизвестная предпосылка — находятся при проверке набора.

## Решения
- **D-1. Один файл — один урок**, как у текстов: удобно писать и править по одному; путь собирается по `topic` + `order`.
- **D-2. В файле — только то, что нельзя сгенерировать.** Упражнения «узнать / услышать / вспомнить» плеер строит сам из слов урока (перевод, озвучка, формы, примеры словаря); вручную — только «применить»: вставь слово в предложение (`fill`), собери фразу из блоков (`build`), переведи фразу (`translate`).
- **D-3. Слова — ссылки на id словаря языка урока**, без копий: правка перевода в словаре сразу видна во всех уроках.
- **D-4. id урока — ключ прогресса урока** (`lesson:<id>`): slug, не меняется.
- **D-5. Состав урока (3–5 слов, глагол + существительное + наречие/прилагательное) — предупреждение**, не ошибка: методика, а не формат.
- **D-6. Один формат на все виды уроков** (`kind`: `words` → `sound`, `grammar`): общий заголовок и путь, разные тела; незнакомый `kind` — ошибка.

## Подход
Спека `.flow/lesson-format.md` → типы → тесты-вперёд → валидатор на `Checker` (файл) + набор (`validateLessonSet(lessons, dictionaries)`) → схема → пример `content/lessons/es-travel-01.json` (+ нужные слова в пример словаря) → `content.spec` → сообщения i18n.

## Тесты
Класс риска: **К2** (валидация), **К1** — уникальность id урока (ключ прогресса). Таблица — в `lessons/domain/validate.spec.ts` по правилам спецификации.

## Ключ к корректности / риски
Ссылки урока на словарь — по id статьи (ключ прогресса), а не по лемме: лемма может совпасть у омонимов. Пропуск в `fill` — ровно один, ответ — форма слова урока, иначе упражнение проверяет не то.

## Итог реализации
**Сделано.** Спецификация `.flow/lesson-format.md` (D-20): общий заголовок всех видов уроков и вид `words`; таблица «что в файле, что генерирует плеер». `features/lessons`: типы, валидатор урока на `Checker` (структура, фраза дня, мини-правило, упражнения `fill` с ровно одним пропуском, `build`, `translate`; самоссылка в `requires`) и набора со словарём (повтор id, имя файла, повтор места в пути, неизвестная предпосылка, слово не из словаря; предупреждения — число слов, состав «глагол + существительное + наречие/прилагательное», ответ `fill` не форма слова урока). Схема `content/schema/lesson.schema.json`. Пример `content/lessons/es-travel-01.json` (tener, reserva, aquí; фраза, правило, 4 упражнения), в пример словаря добавлен `es.adverbs.json`. Сообщения RU/EN/ES.
