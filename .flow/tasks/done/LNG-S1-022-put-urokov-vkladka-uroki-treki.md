## Цель
Вкладка «Уроки»: ученик видит весь путь по каждому изучаемому языку — темы «путешествия» и IT, уроки по порядку, статус каждого (пройден / пропущен как знакомый / следующий / открыт) — и может открыть любой урок, в том числе повторно.

## Объём
**Входит:** вкладка «Уроки» (язык × тема в URL), список уроков слов трека с названием, статусом, лучшей оценкой, числом пройденных; вход в любой урок; «следующий» выделен; чистое ядро статусов; `nextLesson` — на общем ядре.
**Не входит:** уроки звучания и грамматики в пути (их плееры — BL-18, BL-10); чередование «после 2 уроков слов — грамматика» (D-14); блокировка уроков (все открыты — путь рекомендует, а не запрещает).

## Критерии приёмки (AC-1…N)
- **AC-1.** Вкладка «Уроки» показывает язык (из профиля) и тему; выбор хранится в URL.
- **AC-2.** Уроки темы — по `order`; у каждого статус: «Пройден» (с лучшей оценкой), «Знакомые слова» (все слова известны, не пройден), «Следующий», иначе «Открыт».
- **AC-3.** Касание урока открывает плеер; после прохождения возврат на вкладку показывает обновлённый статус.
- **AC-4.** Верх экрана — «Пройдено K из N» по языку; у языка без уроков — понятное пустое состояние.
- **AC-5.** «Следующий» в пути совпадает с «Следующим» на «Главной».

## Решения
- **D-1. Один источник «следующего»:** `nextLesson` отдаёт и уроки с их статусами; «Главная» и вкладка не расходятся.
- **D-2. Уроки не блокируются:** «Открыт» доступен всегда, `requires` влияет только на «следующий» (D-6 LNG-S1-017).

## Ключ к корректности / риски
Статус «Знакомые слова» не должен перекрывать «Пройден»; «следующий» — ровно один на язык.

## Тесты
К2 — unit на статусы (пройден > знакомые > следующий > открыт, один следующий). Экран — К3, смоук.
