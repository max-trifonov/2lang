## Цель
Интерфейс целиком говорит на языке профиля: ни одной строки мимо словаря, у документа правильный `lang`, числа согласуются со словами по правилам языка.

## Критерии приёмки
- **AC-1.** Любой ключ есть во всех трёх словарях (RU/EN/ES) — иначе падает `npm run test`.
- **AC-2.** `<html lang>` всегда равен языку интерфейса (озвучка и скринридер читают с нужным произношением).
- **AC-3.** «Цель дня: 1 урок / 2 урока / 5 уроков», «1 lesson / 2 lessons», «1 lección / 2 lecciones».
- **AC-4.** Кнопка «Назад» подписана на языке интерфейса (iOS-режим Ionic показывает текст).

## Ключ к корректности / риски
Правила множественного числа — по `Intl.PluralRules`, а не самописной арифметике: русские «11–14» и дробные числа. Синхронизация `lang` и plural — ядро: возвращаются в `templates-app`.
