## Контекст / зачем
Слова сейчас приходят только из уроков и быстрой проверки, а словарь — 900+ статей — только читается. Заказчик хочет учить слова прямо по словарю: в любой момент, по выбранному языку и части речи, чтобы приложение само подбирало новые слова по частоте и возвращало забытые и ошибочные (brief: «повторение по выбору: … часть речи», `D-9`).

## Цель
Во вкладке «Словарь» — кнопка «Тренировка»: выбираешь язык и раздел, получаешь раунд из ~15 слов (просроченные к повторению + до 5 новых в порядке частоты + «трудные»), отвечаешь в основном «слово → перевод», иногда «перевод → выбери слово», ответы идут в FSRS.

## Объём
**Входит:**
- экран `/train?lang=&list=`: выбор языка (языки профиля) и раздела (все, глаголы, существительные, прилагательные, наречия, «мои слова», «с ошибками»), счётчики «к повторению / новых / с ошибками», «Начать»;
- подбор раунда (чистая функция): сначала к повторению по сроку (самые забытые — с меньшей запоминаемостью — первыми, при равенстве — более сложные), затем новые — отмеченные «не знаю» в быстрой проверке, потом по рангу частоты (части речи вперемешку по рангу); известные по проверке слова новыми не считаются; если места остаются — досрочные повторы самых «слабых» (кроме повторённых сегодня);
- новое слово: карточка знакомства (слово, озвучка, перевод, пример) → «узнай перевод» → в конце раунда «выбери слово по переводу»;
- задание по зрелости карточки: S < 3 — «узнай перевод»; дальше в основном «узнай перевод», иногда «выбери слово по переводу», «услышь» (если есть голос), у зрелых (S ≥ 21) — иногда «напиши слово»;
- оценка FSRS одна на слово за раунд: все задания слова с первого раза верно — «Хорошо», с подсказкой написания — «Трудно», хоть одна ошибка — «Забыл»; ошибка возвращает задание в конец раунда (не оценивается повторно);
- итог: точность, сколько новых и повторённых, слова с ошибками со ссылкой на карточку, «Ещё раунд»;
- новое задание плеера `pick` (перевод → слово из 4 вариантов той же части речи, у существительных ES — с артиклем) — доступно и урокам;
- оценённое слово записывается в журнал активности (серия дней).

**Не входит:**
- фильтр по теме (travel/IT) и повторение звучания, грамматики, фраз и песен (остаток пункта BL-5 «по разделам»);
- настройка размера раунда и числа новых слов;
- распознавание речи.

## Критерии приёмки (AC-1…N)
- **AC-1.** Во вкладке «Словарь» есть «Тренировка»; экран тренировки открывается с языком и разделом, выбранными в словаре, и позволяет сменить их до старта.
- **AC-2.** Раунд берёт сначала слова к повторению этого языка и раздела, затем до 5 новых по частоте (сперва отмеченные «не знаю»), не больше 15 слов; известные по быстрой проверке новыми не предлагаются.
- **AC-3.** Новое слово сначала показывается карточкой, затем проверяется «слово → перевод» и в конце раунда «перевод → выбери слово».
- **AC-4.** Большинство заданий — «слово → перевод»; «перевод → выбери слово» встречается в каждом раунде с повторениями.
- **AC-5.** Ошибка возвращает задание в конец раунда; слово с ошибкой получает «Забыл» и возвращается к повторению завтра; верное — уходит по интервалу FSRS. Одно слово — одна оценка за раунд.
- **AC-6.** Раздел «с ошибками» собирает слова, на которых ученик ошибался (провалы или высокая сложность FSRS), даже если срок не подошёл.
- **AC-7.** Итог показывает точность, число новых и повторённых слов и слова с ошибками; «Ещё раунд» подбирает следующий раунд с теми же настройками.

## Подход
1. `lessons/player/practice.ts`: задание `pick` + фабрика `pickTask`; `PracticeTask.vue` рисует его (вопрос — перевод, варианты — на изучаемом языке).
2. `features/train/`: `plan.ts` — подбор раунда и счётчики разделов (`planRound`, `scopeStats`); `steps.ts` — шаги раунда (`trainKind`, `buildRound`: знакомство, оцениваемые задания, закрепление новых), `session.ts` — очередь и оценка слова по всем его заданиям (`startRound`, `answerRound`).
3. `lessons/ui/WordIntro.vue` — карточка знакомства, общая для урока и тренировки (вынести из `LessonPage`).
4. `pages/train/TrainPage.vue` (`/train`): настройка → раунд → итог; запись карточек через `useCardsStore.putMany`, журнал — `activity.record('review')`.
5. Кнопка «Тренировка» в `DictionaryPage`; i18n RU/EN/ES.

| `pickTask` | вопрос — перевод, ответ среди 4 разных вариантов той же части речи, артикль у сущ. ES |

## Ключ к корректности / риски
Оценка слова — ровно одна за раунд и только после всех его заданий: иначе новое слово получит две оценки FSRS подряд (вторая — с почти нулевым интервалом) или ошибка «исправится» повтором. Подбор не должен выдавать новыми слова, уже имеющие карточку или известные по проверке.
