## Контекст / зачем
Ядро гипотезы MVP — короткий урок, который проходишь за 5–7 минут. Форматы, словарь и уроки-примеры готовы, но пройти урок в приложении пока нельзя.

## Цель
Урок слов (`kind: words`) проходится в приложении от начала до итога: знакомство со словами, фраза дня, мини-правило, практика по лестнице «узнать → услышать → вспомнить → применить», итог; прохождение запоминается в профиле.

## Объём
**Входит:**
- Экран урока `/lessons/:id` вне вкладок; шаги: новые слова (из словаря: артикль, перевод, транскрипция, пример по теме урока, озвучка) → фраза дня (+ пояснение, озвучка) → мини-правило с примерами → практика → итог.
- Практика плеера из слов урока: «узнать» (слово → перевод из 4), «услышать» (голос → написание из 4; без голоса — пропуск), «вспомнить» (перевод → набрать слово); «применить» — упражнения файла `fill` / `build` / `translate`.
- Сверка ответа, повтор ошибочного задания в конце, итог (верно с первого раза, слова урока со ссылками на карточки).
- Прогресс урока профиля: стор ученика `lesson_progress` (миграция v4), в резервной копии и каскадном удалении.
- Временная точка входа на «Главной»: «следующий урок» по каждому изучаемому языку.

**Не входит:**
- Разминка из повторения и отправка слов в FSRS — BL-5.
- Плееры уроков звучания и грамматики — свои задачи BL-18, BL-10.
- Путь уроков по темам (BL-4), экран «Сегодня», цель дня и серия (BL-7).

## Критерии приёмки (AC-1…N)
- **AC-1.** С «Главной» урок открывается кнопкой «Начать»; если уроков языка нет или все пройдены — об этом сказано.
- **AC-2.** Шаги идут по порядку: каждое новое слово (перевод, артикль, транскрипция, пример, озвучка) → фраза дня → мини-правило (если есть) → практика → итог; прогресс-полоса показывает, где ученик.
- **AC-3.** В практике по каждому слову есть «узнать», «услышать» (если есть голос языка) и «вспомнить», затем все упражнения «применить» из файла.
- **AC-4.** Ответ сверяется без учёта регистра, лишних пробелов и знаков по краям; ответ без ударения или тильды засчитывается с подсказкой правильного написания.
- **AC-5.** На ошибку показывается правильный ответ, задание повторяется в конце практики один раз.
- **AC-6.** Итог показывает долю верных с первого раза и слова урока; урок отмечен пройденным в профиле, «Главная» предлагает следующий.
- **AC-7.** Выход из урока до итога прогресс не меняет; несуществующий урок — понятное «урок не найден».
- **AC-8.** Прохождения переживают перезапуск, попадают в резервную копию профиля и удаляются вместе с профилем.

## Решения
- **D-1. Разминка пропускается до BL-5**: без повторения FSRS нечего разминать; шаг добавит BL-5.
- **D-2. Лестница по стадиям**, а не по словам: сначала «узнать» все слова, потом «услышать», потом «вспомнить», затем «применить» в порядке файла. Отвлекающие варианты — другие слова урока, добор — слова той же части речи словаря, ближайшие по рангу. Перевод в вариантах — до первой «;».
- **D-3. Сверка**: NFC, нижний регистр, схлопнутые пробелы, без знаков препинания по краям (¿¡.,!?…); совпадение без диакритики — «верно, но с подсказкой» (`accent`), засчитывается. Для `build` сравнивается собранная строка тем же способом.
- **D-4. Ошибка** — правильный ответ на экране, задание в конец очереди один раз; оценка = верно с первого раза / заданий.
- **D-5. Прогресс урока** — стор ученика `lesson_progress`, ключ `[profileId, key]`, `key = lesson:<id>`; поля `firstCompletedAt`, `completedAt`, `runs`, `bestScore`. Пишется только на итоге.
- **D-6. «Следующий урок»** языка — первый непройденный урок слов с выполненными `requires`; треки по порядку тем `travel → it → daily`, внутри — `order`. Временно, до пути уроков и «Сегодня».
- **D-7. Выход без подтверждения**: урок короткий, шаг не сохраняется; подтверждение вернём, если на смоуке семьи это будет мешать.

## Подход
Чистые функции в `features/lessons/player/` (сверка, разбиение на блоки, план практики с инъекцией rng, сессия-очередь с повтором, выбор следующего урока) — под unit-тесты. Репозиторий + стор прогресса по образцу `saved.ts`. UI — компоненты заданий в `features/lessons/ui/`, страница собирает шаги из плана.

## Тесты
Класс риска: К2 — unit на `answer`, `blocks`, `practice`, `session`, `next`, `progress` (репозиторий на fake-indexeddb) и миграцию v4. К3 (экраны) — без тестов, ручной смоук по AC.

| Вход | Ожидание |
|---|---|
| `"  Tengo. "` vs `Tengo` | exact |
| `aqui` vs `aquí` | accent |
| `¿Tienes reserva?` vs `tienes reserva` | exact |
| урок из 3 слов, голос есть | 9 заданий плеера + упражнения файла; стадии по порядку |
| голоса нет | без «услышать» |
| ошибка в задании | задание в конце очереди один раз, оценка не засчитывает |
| пройден es-travel-01 | следующий — непройденный с выполненными requires |

## Ключ к корректности / риски
Отвлекающие варианты не должны совпадать с правильным (одинаковые переводы у разных слов — вариант с тем же текстом исключается). Повтор ошибки — ровно один раз, иначе урок может не закончиться.

## Итог реализации
**Сделано.** Экран урока `pages/lessons/LessonPage.vue` (`/lessons/:id`, вне вкладок, крестик закрывает без сохранения): новые слова (артикль, перевод, транскрипция, пример по теме урока, озвучка) → фраза дня с пояснением → мини-правило с примерами → практика → итог (верно с первого раза N из M, слова урока со ссылками на карточки, «пройти ещё раз»); полоса прогресса; состояния loading / «урок не найден» / ошибка с повтором.
