## Цель
В карточке слова — блок «Как читать»: правила чтения из уроков звучания, на которые ссылается статья (`rules`): название, короткое объяснение, звук (IPA), со ссылкой на тему программы (ES-P3).

## Критерии приёмки
- **AC-1.** У слова с `rules` (hacer: c перед e/i, немая h) карточка показывает эти правила на языке интерфейса.
- **AC-2.** Правило, которого нет ни в одном уроке, не ломает карточку (просто не показывается); у слова без `rules` блока нет.
- **AC-3.** Работает офлайн (уроки в сборке, как словари).

## Ключ к корректности / риски
Правила ищутся по глобальному id (D-21) среди уроков вида `sound` того же языка — урок другого языка с тем же id не должен подмешаться.
