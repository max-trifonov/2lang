# Черновики словаря — ИИ (D-25)

Партии: `batch-4/` — остаток каркаса и слова вне каркаса (LNG-S1-032, EN 2001 / ES 1960 статей), `batch-1/` — топ-100 каждого списка + слова первых уроков (LNG-S1-013), `batch-2/` — слова уроков ES es-travel-02…10, es-it-01…10 (LNG-S1-018), `batch-3/` — слова уроков EN en-travel-*, en-it-* (LNG-S1-020). Исходники партии: `<язык>_<часть речи>.py` — перевод, примеры, неправильные формы, пары. Лемма — только в одной партии.

`build.py` собирает их в `content/dictionary/` (ранг, род, id — из каркаса `content/frequency/`; правильные формы ES — по правилам; `rules` ES — по написанию; обратные пары ES → EN).

Источник истины после сборки — `content/dictionary/*.json`: автор выверяет статьи там и снимает пометку `ext.draft`. **Сборка по умолчанию — слияние** (D-28): статьи, уже лежащие в словаре, не меняются (ни поля, ни пары, ни заголовок файла), добавляются только новые; повторный запуск ничего не меняет. `--rebuild` пересобирает словарь из черновиков целиком и **стирает выверку** — только осознанно.

```bash
python3 content/drafts/build.py            # слияние: добавить новые статьи
python3 content/drafts/build.py --rebuild  # пересборка с нуля (сотрёт выверку)
```

Производные данные — CC BY-SA 4.0 (см. `content/frequency/NOTICE.md`).

## Партия 4 и компактная запись (LNG-S1-032)

`batch-4/<язык>_<часть речи>.py` пишутся через `dsl.py`: одна строка = одна статья `лемма | перевод | пример | перевод примера | тема | опции | заметка`. Формы EN (`-s/-ed/-ing`, степени сравнения) и ES (правильное спряжение + теги чередований `ie ue i ie-i ue-u`, `zco`, `jo`, `uy`, `ey`, `pres= pret= ger= part=`) строит код. Опции: `irr=past/part`, `dbl`, `pl=`, `nopl`, `er`/`more`/`cmp=`, `pair=<лемма>` (разрешается в id статьи второго языка, обратная пара у ES — автоматически), `lvl=` (только слова вне каркаса).

`<язык>_<часть речи>_x.py` — **слова вне каркаса** (прилагательные и наречия сверх топ-200): ранг 201+, `ext.extra`. Лемма уже в каркасе — пропускается.

Уровень `level` берётся из `cefr` каркаса (слияние добавляет его и прежним статьям).

`lessons/gen.py` (описания `en.txt`, `es.txt`) пишет `content/lessons/*.json`, `texts/gen.py` (`texts.txt`) — `content/texts/*.json`. Формат описаний — в шапке скриптов.

## Грамматика (LNG-S1-033, D-38)

`grammar/gen.py` (описания `grammar/en.txt`, `grammar/es.txt`, формат — в шапке скрипта) пишет темы грамматики `content/lessons/<язык>-grammar-NN.json` и запускает `grammar/link.py` — отсылки уроков слов к правилам (`see`, эвристика по шаблонам конструкций). `lessons/gen.py` тоже вызывает `link.py` в конце. Ручная правка `see` в уроке слов перезапуском стирается — правьте шаблоны в `link.py`.
