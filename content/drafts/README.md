# Черновики словаря — ИИ (D-25)

Партии: `batch-1/` — топ-100 каждого списка + слова первых уроков (LNG-S1-013), `batch-2/` — слова уроков ES es-travel-02…10, es-it-01…10 (LNG-S1-018), `batch-3/` — слова уроков EN en-travel-*, en-it-* (LNG-S1-020). Исходники партии: `<язык>_<часть речи>.py` — перевод, примеры, неправильные формы, пары. Лемма — только в одной партии.

`build.py` собирает их в `content/dictionary/` (ранг, род, id — из каркаса `content/frequency/`; правильные формы ES — по правилам; `rules` ES — по написанию; обратные пары ES → EN).

Источник истины после сборки — `content/dictionary/*.json`: автор выверяет статьи там и снимает пометку `ext.draft`. **Сборка по умолчанию — слияние** (D-28): статьи, уже лежащие в словаре, не меняются (ни поля, ни пары, ни заголовок файла), добавляются только новые; повторный запуск ничего не меняет. `--rebuild` пересобирает словарь из черновиков целиком и **стирает выверку** — только осознанно.

```bash
python3 content/drafts/build.py            # слияние: добавить новые статьи
python3 content/drafts/build.py --rebuild  # пересборка с нуля (сотрёт выверку)
```
